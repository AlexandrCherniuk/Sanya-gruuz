# Заявки с сайта в Telegram

Как это работает: человек жмёт «Отримати ціну» → сайт шлёт заявку в маленький скрипт
в твоём Google-аккаунте (Google Apps Script, бесплатно) → скрипт шлёт сообщение твоим ботом в Telegram.

Токен бота лежит только в Google, в репозитории его нет и быть не должно (репо публичный).

## Что сделать один раз (минут 10)

### 1. Бот
1. В Telegram открой **@BotFather**, отправь `/newbot`, придумай имя и username (на `bot` в конце).
2. BotFather пришлёт токен вида `123456789:AA...`. Никому не пересылай и не вставляй в чаты, только в шаг 2.
3. Открой своего бота и нажми **Start**. Если заявки должны падать в группу (тебе и менеджерам),
   создай группу, добавь туда бота и напиши в группе любое сообщение.

### 2. Скрипт
1. Зайди на <https://script.google.com> → **Новый проект**. Назови, например, «Заявки сайт».
2. Сотри всё в редакторе и вставь целиком файл [`Code.gs`](./Code.gs). Сохрани (Ctrl+S).
3. Слева шестерёнка **Настройки проекта** → внизу **Свойства скрипта** → **Добавить**:
   - `TG_TOKEN` = токен от BotFather
4. Вернись в редактор, сверху выбери функцию `findChatId` → **Выполнить**. Google попросит доступ, разреши
   (это твой же скрипт). Внизу в журнале будет `chat id: ...`. Скопируй число (у группы оно с минусом).
5. Добавь второе свойство: `TG_CHAT_ID` = это число. Несколько чатов можно через запятую.
6. Выбери функцию `testTelegram` → **Выполнить**. В Telegram должно прийти «Бот заявок підключено».

### 3. Опубликовать скрипт
1. Справа сверху **Развернуть → Новое развертывание** → тип **Веб-приложение**.
2. «Запуск от имени»: **Я**. «Кто имеет доступ»: **Все**.
3. **Развернуть** → скопируй **URL веб-приложения** (заканчивается на `/exec`).

### 4. Подключить к сайту
Сейчас адрес уже вшит в `src/lead.ts` (`DEFAULT_ENDPOINT`). Если делаешь новый скрипт, поменяй его там или задай переменную:

В GitHub: репозиторий → **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**:
- Name: `LEAD_ENDPOINT`, Value: URL из шага 3.

Потом пересобери сайт, чтобы он подхватил адрес: вкладка **Actions → Deploy GitHub Pages → Run workflow → Run workflow**.
Через 1–2 минуты, когда прогон станет зелёным, форма начнёт слать заявки.

## CRM: группа + таблица «Ліди CR Logistics» + контроль в личке

**Как работает**
- Заявка с сайта приходит в группу карточкой `CR-0211-01` (день и месяц + номер за день) с кнопкой «🙋 Взяти заявку».
- Взял → в карточке «Взяв: Іван», кнопки «🔄 Передати» и «📋 Таблиця».
  В таблице «Ліди» сама появляется строка: №, дата, менеджер, статус «Прорахунок», телефон, маршрут, груз, имя, источник.
- Дальше менеджер работает **в таблице**: статус (список), клиент/компания, про бизнес, вес/объём,
  дата загрузки, перевозчик, цены, условия и срок оплаты, комментарий. Колонка «Оновлено» ставится сама.
- Статус из таблицы бот сам переносит в карточку в группе (сразу при правке и раз в 5 минут).
- «🔄 Передати» может тот, кто взял, и админ. В таблице меняется менеджер, новому и старому пинг в личку.
- Лист **«Пошук»**: пиши в жёлтую клетку клиента, телефон, город, перевозчика или номер, внизу все совпадения.

**Коментарі та нагадування прямо в Telegram**
- «💬 Коментар» под заявкой (в группе или в личке) → бот просит текст, ответ попадает в карточку и в колонку «Коментар» таблицы
  с датой и именем. Можно и просто ответить (Reply) на любое сообщение бота про заявку.
  Если пишет не менеджер заявки (например, админ «зроби швидше»), менеджеру приходит пинг в личку.
- «⏰ Нагадати» — только в личке с ботом (в группе кнопка открывает личку сразу на этой заявке): 30 хв / 1 год / 3 год / завтра 9:00 / завтра 14:00 / свой час
  (`16:30`, `завтра 10:00`, `05.11 9:00`, `через 2 год` + текст, о чём напомнить).
  Напоминание приходит в личку тому, кто поставил, с точностью до 5 минут.
- Номер заявки (`CR-0211-01`) боту в личку → бот покажет заявку с кнопками.

**🤖 ИИ-помощник (по желанию, нужен ключ Claude API)**
Помощник работает с заявками через инструменты бота: сам ищет в таблице, записывает, считает. Ничего не выдумывает:
нет в данных — так и скажет. Знает только нужное о бизнесе: направления, статусы, правила контроля, условия оплаты.
- **В личке** пиши ему как человеку, он помнит разговор 6 часов:
  «що в мене без ціни?», «статистика за жовтень по менеджерах», «які заявки висять у прорахунку?»,
  «по CR-0311-02 перевізник Іваненко, 18 000 грн, оплата при вивантаженні» (запишет в таблицу и в коментар),
  «передай CR-0311-02 Олегу», «нагадай завтра о 10 передзвонити Петренку» (можно и без заявки),
  «мої нагадування», «скасуй нагадування».
- **В группе** — ответ (Reply) на карточку или сообщение бота: коментар → в карточку и таблицу, данные из него
  раскладываются по пустым колонкам; «удали коментар», «закрили», «в роботу» тоже понимает. Нагадування — только в личке.
- Права те же, что у кнопок: статус и передачу меняет менеджер заявки или админ.
- Бот отвечает только своим: админам и участникам группы заявок.
- Включить: на console.anthropic.com пополни баланс, создай API key → в свойства скрипта `ANTHROPIC_API_KEY`
  → функция **testAI** (в журнале должен быть ✅ и короткая статистика). Без ключа всё работает, просто без ИИ.
- Модель `claude-haiku-5-5` — самая дешёвая: примерно 0,1–0,5 цента за сообщение, при 50 сообщениях в день ≈ 1–5 $
  в месяц. Чтобы она не ошибалась, в подсказке подробные правила, примеры и готовые даты («вчора», «цей тиждень»…).
  Умнее, но в ~20 раз дороже: свойство `AI_MODEL` = `claude-sonnet-5-5`. `AI_EFFORT` = `low` / `medium` / `high`
  (по умолчанию `medium`), не больше 400 запросов к ИИ в день (`AI_DAILY_LIMIT`; одно сообщение = 1–6 запросов).

**Личка менеджера с ботом = только контроль**
- взял, а цены клиенту нет 2 часа → «зроби прорахунок»; сутки → ещё раз + в группу;
- «В роботі», а не заполнены перевозчик / цена / оплата / клиент → раз в день;
- «В планах» → напоминание за день до загрузки; дата прошла → «онови статус»;
- «В роботі» через 3 дня после загрузки → «закрий або онови»;
- в 9:00 каждому его открытые заявки, в группу общая сводка.
- Не нажал Start у бота → напоминание уходит в группу с его именем.

## Проверка
Открой сайт, оставь заявку со своим номером. Через пару секунд в Telegram придёт:

```
🚚 Нова заявка з сайту

📞 +380XXXXXXXXX
📍 Київ → Варшава
📦 Меблі
```

Если человек пришёл с рекламы Google, в заявке будет строка `🎯 gclid=…` / `utm_campaign=…`:
видно, какая кампания дала заявку.

## Если что-то пошло не так
- **Форма пишет «Не вдалося надіслати»**: не задана переменная `LEAD_ENDPOINT` или скрипт развёрнут не с доступом «Все».
- **Поменял код скрипта**: **Развернуть → Управление развертываниями → карандаш → Версия: новая**, иначе работает старый код. URL при этом не меняется.
- **Токен утёк**: в @BotFather `/revoke`, новый токен вставь в `TG_TOKEN`. Сайт трогать не надо.

## Защита от спама
- Скрытое поле-ловушка для ботов.
- Не больше 3 заявок с одного номера за 10 минут.
- Если начнут спамить всерьёз, добавим капчу (Cloudflare Turnstile, бесплатно).
