# Заявки с сайта в Telegram

Как это работает: человек жмёт «Отримати ціну» → сайт шлёт заявку в маленький скрипт
в твоём Google-аккаунте (Google Apps Script, бесплатно) → скрипт шлёт сообщение твоим ботом в Telegram.

Токен бота лежит только в Google, в репозитории его нет и быть не должно (репо публичный).

## Что сделать один раз (минут 10)

### 1. Бот
1. В Telegram открой **@BotFather**, отправь `/newbot`, придумай имя и username (на `bot` в конце).
2. BotFather пришлёт токен вида `123456789:AA...`. Никому не пересылай и не вставляй в чаты, только в шаг 2.
3. Открой своего бота и нажми **Start**. Если заявки должны падать в группу (тебе и менеджерам),
   создай группу, добавь туда бота и напиши в группе любое сообщение.

### 2. Скрипт
1. Зайди на <https://script.google.com> → **Новый проект**. Назови, например, «Заявки сайт».
2. Сотри всё в редакторе и вставь целиком файл [`Code.gs`](./Code.gs). Сохрани (Ctrl+S).
3. Слева шестерёнка **Настройки проекта** → внизу **Свойства скрипта** → **Добавить**:
   - `TG_TOKEN` = токен от BotFather
4. Вернись в редактор, сверху выбери функцию `findChatId` → **Выполнить**. Google попросит доступ, разреши
   (это твой же скрипт). Внизу в журнале будет `chat id: ...`. Скопируй число (у группы оно с минусом).
5. Добавь второе свойство: `TG_CHAT_ID` = это число. Несколько чатов можно через запятую.
6. Выбери функцию `testTelegram` → **Выполнить**. В Telegram должно прийти «Бот заявок підключено».

### 3. Опубликовать скрипт
1. Справа сверху **Развернуть → Новое развертывание** → тип **Веб-приложение**.
2. «Запуск от имени»: **Я**. «Кто имеет доступ»: **Все**.
3. **Развернуть** → скопируй **URL веб-приложения** (заканчивается на `/exec`).

### 4. Подключить к сайту
Сейчас адрес уже вшит в `src/lead.ts` (`DEFAULT_ENDPOINT`). Если делаешь новый скрипт, поменяй его там или задай переменную:

В GitHub: репозиторий → **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**:
- Name: `LEAD_ENDPOINT`, Value: URL из шага 3.

Потом пересобери сайт, чтобы он подхватил адрес: вкладка **Actions → Deploy GitHub Pages → Run workflow → Run workflow**.
Через 1–2 минуты, когда прогон станет зелёным, форма начнёт слать заявки.

## Кнопка «Взяти заявку» для менеджеров

Под каждой заявкой есть кнопка «🙋 Взяти заявку». Кто первый нажал, того бот и пишет:
`✅ Взяв: Іван Петренко (@ivan) · 02.11 14:32`. Отметка появляется во всех копиях заявки
(и в личке, и в группе), кнопка пропадает, второй раз взять нельзя.

### Как обновить скрипт (один раз)
1. Открой скрипт на script.google.com, в редакторе выдели весь код и замени на новый [`Code.gs`](./Code.gs). Сохрани.
2. **Развернуть → Управление развертываниями** → карандаш ✏️ у активного развертывания → «Версия»: **Новая версия** → «Развернуть».
   Не делай «Новое развертывание»: у него будет другой адрес, и сайт перестанет слать заявки.
3. В списке функций выбери **setupButtons** → «Выполнить». Это говорит Telegram, куда слать нажатия кнопок.
4. Выбери **testTelegram** → «Выполнить». Придёт тестовое сообщение с кнопкой, нажми её.
   Сообщение должно поменяться на «✅ Взяв: …».

### Если кнопка не реагирует
Запусти **checkButtons**: в журнале будет «Последняя ошибка». Скинь скрин.
Выключить кнопки: **disableButtons** (заявки продолжат приходить, просто без кнопки).

### Чат-id после включения кнопок
Когда кнопки включены, `findChatId` берёт чаты из запомненных: добавь бота в новую группу
и запусти `findChatId` (если не видно, удали бота из группы и добавь снова).

## Проверка
Открой сайт, оставь заявку со своим номером. Через пару секунд в Telegram придёт:

```
🚚 Нова заявка з сайту

📞 +380XXXXXXXXX
📍 Київ → Варшава
📦 Меблі
```

Если человек пришёл с рекламы Google, в заявке будет строка `🎯 gclid=…` / `utm_campaign=…`:
видно, какая кампания дала заявку.

## Если что-то пошло не так
- **Форма пишет «Не вдалося надіслати»**: не задана переменная `LEAD_ENDPOINT` или скрипт развёрнут не с доступом «Все».
- **Поменял код скрипта**: **Развернуть → Управление развертываниями → карандаш → Версия: новая**, иначе работает старый код. URL при этом не меняется.
- **Токен утёк**: в @BotFather `/revoke`, новый токен вставь в `TG_TOKEN`. Сайт трогать не надо.

## Защита от спама
- Скрытое поле-ловушка для ботов.
- Не больше 3 заявок с одного номера за 10 минут.
- Если начнут спамить всерьёз, добавим капчу (Cloudflare Turnstile, бесплатно).
